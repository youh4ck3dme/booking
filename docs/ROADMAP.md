# Feature Roadmap

## v1.1.0 - Enhanced UX (Target: Q1 2026)

### Calendar View
- [ ] **Monthly Calendar Component**
  - Visual grid showing all bookings
  - Color-coded by status (confirmed, pending, cancelled)
  - Click to view booking details
  - Drag-and-drop rescheduling (admin only)
  
- [ ] **Week View**
  - Timeline view (9 AM - 6 PM)
  - Employee columns
  - Booking blocks with customer info
  
- [ ] **Day View**
  - Detailed hourly breakdown
  - Available slots highlighted
  - Quick booking creation

### Push Notifications
- [ ] **Browser Push API Integration**
  - Request permission on first booking
  - Send reminders 24h before appointment
  - Send confirmation notifications
  
- [ ] **Notification Preferences**
  - User settings for notification types
  - Frequency control
  - Quiet hours

### Analytics Dashboard (Admin)
- [ ] **Key Metrics**
  - Total bookings (daily/weekly/monthly)
  - Revenue tracking
  - Popular services
  - Employee utilization
  
- [ ] **Charts & Visualizations**
  - Line chart: Bookings over time
  - Pie chart: Service distribution
  - Bar chart: Employee performance
  
- [ ] **Export Functionality**
  - CSV export for reports
  - PDF generation for invoices
